# Каталог в кармане — трикотаж оптом (демо)

Ссылка-каталог, которую продавец кидает клиенту в WhatsApp вместо десятков фотографий:
все модели, размеры, остатки и **лестница цен** «чем больше заказ — тем ниже цена». Заказ уходит продавцу в WhatsApp одной кнопкой.

**Демо:** https://planetasofa2012-code.github.io/katalog-optom/
**Заявки (для продавца):** https://planetasofa2012-code.github.io/katalog-optom/#admin

> Товары и цены выдуманы для примера.

## Что умеет
- Каталог с фильтрами (категория, размер, наличие), крупный шрифт для 40+
- Цены в 3 ступени: штучная → от N шт модели → от суммы заказа (опт на всё)
- Корзина сама выбирает ступень и пишет «ещё N ₽ — и цена оптовая»
- Заказ: имя, телефон, 2 галочки (ПДн — обязательна, рассылки — по желанию) → WhatsApp с готовым текстом
- «Позвоните мне», «Где нас найти», политика ПДн
- Ставится на телефон как приложение (PWA), но работает и просто по ссылке
- 0 ₽/мес: GitHub Pages + Google-таблица + Apps Script

## Как устроено
```
docs/            сайт (GitHub Pages)
  config.js      номер WhatsApp, порог опта, ссылка на таблицу
  data/          демо-каталог
google/          скрипт приёма заявок в Google-таблицу
0_research.md …  документация проекта
```

## Запуск локально
```bash
cd docs && python -m http.server 8080
# открыть http://localhost:8080
```
