# 3. Архитектура

## Схема
```
 Лёха / продавец                                     Клиент (телефон)
 ┌──────────────┐  правит   ┌─────────────────┐  CSV  ┌───────────────────────┐
 │ 1С (остатки) │ ───────▶ │ Google-таблица   │ ────▶ │ PWA на GitHub Pages    │
 └──────────────┘ выгрузка │ «Товары»,        │       │ каталог → корзина →    │
   (v2: авто)              │ «Настройки»      │       │ форма + 2 галочки      │
                           │ «Заявки» ◀───────┼───────┤ POST (Apps Script)     │
                           └─────────────────┘       │ ──▶ wa.me Лёхе с текстом│
                                                      └───────────────────────┘
```

## Структура репозитория
```
/
├─ 0_research.md … 5.1_tasks.md, PROTOCOL.md   — документация по Георгию
├─ docs/                     — сам сайт (GitHub Pages → /docs)
│  ├─ index.html             — оболочка приложения
│  ├─ styles.css
│  ├─ app.js                 — каталог, корзина, цены, форма
│  ├─ config.js              — URL таблицы, URL Apps Script, WhatsApp
│  ├─ data/products.json     — демо-каталог (фолбэк, если таблица не подключена)
│  ├─ img/                   — SVG-заглушки фото
│  ├─ privacy.html           — политика ПДн
│  ├─ manifest.webmanifest, sw.js, icon.svg
├─ google/
│  └─ apps_script.gs         — приём заявок в лист «Заявки»
└─ README.md
```

## Модули app.js
| Модуль | Что делает |
|--------|-----------|
| `loadCatalog()` | Если в config есть `SHEET_CSV_URL` — тянет CSV и парсит; иначе `data/products.json`. Кэш в localStorage на офлайн |
| `priceFor(cart)` | Правила лестницы (см. ТЗ) |
| `render*()` | Каталог, карточка, корзина, форма — один файл, без фреймворков |
| `submitOrder()` | POST в Apps Script (если задан) + сохранение в локальные «Заявки» (демо) + открыть `wa.me` |

## Конфиг (`docs/config.js`)
```js
window.APP_CONFIG = {
  SHOP_NAME: "…",
  WHATSAPP: "7913…",        // номер Лёхи
  SHEET_CSV_URL: "",        // пусто = демо-данные
  ORDERS_ENDPOINT: "",      // пусто = заявки только локально
  WHOLESALE_SUM: 30000
};
```

## Деплой
`git push` в `main` → GitHub Pages публикует `/docs` автоматически. Никаких серверов. Подробно — `7_deploy.md` (будет создан на стадии 7).

## Подключение реальной таблицы (когда Лёха даст данные)
1. Создать Google-таблицу с листами «Товары», «Заявки».
2. «Файл → Поделиться → Опубликовать в интернете → лист Товары → CSV» → URL в `SHEET_CSV_URL`.
3. «Расширения → Apps Script» → вставить `google/apps_script.gs` → «Развернуть → Веб-приложение, доступ: все» → URL в `ORDERS_ENDPOINT`.
4. Фото — в папку `docs/img/` репозитория или публичные ссылки.

## 1С → таблица (v2)
- Вариант А (0 ₽): в 1С отчёт «Остатки» → сохранить в Excel → вставить в лист «Остатки» (1 мин в день).
- Вариант Б: включить OData в 1С (публикация на веб-сервере) → Apps Script по расписанию забирает остатки.
- Вариант В: обработка 1С, пишущая в Google Sheets через сервисный аккаунт.
